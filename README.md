# Portafolio de ciberseguridad — Aketx Herrero

Laboratorios de ciberseguridad documentados, publicados con GitHub Pages.
Es una sola página (`index.html`) con pestañas: Inicio y una pestaña por práctica.

- `index.html` — portada con la introducción y todas las prácticas.
- `dvwa/img/` — capturas de la auditoría web de DVWA (SQLi y XSS).
- `ia-local/img/` — capturas del escaneo web asistido por IA local.

Todos los trabajos se realizaron en entornos de laboratorio controlados y con fines formativos.
